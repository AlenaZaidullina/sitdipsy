## 🎯 О проекте

CBT_psy объединяет сайт психолога и Telegram-бота для автоматизации записи,
самодиагностики и рассылок. Проект построен на принципах
когнитивно-поведенческой терапии (КПТ) и решает следующие задачи:

- Для клиентов: удобная запись на консультации, тесты на тревогу и депрессию, 
полезные материалы

- Для психолога: автоматизация сбора заявок и управление рассылками

- Для мам: отдельный канал с практиками сенсорного развития детей

Проект полностью контейнеризирован с помощью Docker и готов к деплою на production-сервер.

## ✨ Функциональность

### Веб-сайт
- **Главная страница** — информация о психологе и услугах
- **Запись на консультацию** — выбор доступного времени и заполнение формы согласия
- **Блог/статьи** — полезные материалы по психологии
- **Канал для мам** — отдельный раздел с сенсорными играми и материалами для развития детей
- **Продукты** — информация о психологических продуктах и гайдах

### Telegram бот [citation:2]
- **Меню с командами**: /menu, /subscribe, /unsubscribe, /appointment
- **Диагностика**: тесты тревоги (BAI) и депрессии (BDI) с интерпретацией результатов
- **Запись**: сбор заявок на консультацию через диалог
- **Рассылки**: подписка на полезные материалы и уведомления о новых датах
- **Автоматизация**: напоминания и follow-up сообщения через Celery

## 🛠 Технологии

### Бэкенд
- **Python 3.11** — основной язык разработки
- **Django 5.2** — веб-фреймворк
- **PostgreSQL 15** — база данных
- **Redis** — кэширование и брокер сообщений
- **Celery** — фоновые задачи и периодические рассылки

### Фронтенд
- **HTML/CSS/JavaScript** — кастомные стили
- **Адаптивная верстка** — мобильные и десктопные версии

### Telegram бот
- **python-telegram-bot 22.3** — асинхронная работа с Telegram API
- **Inline и Reply клавиатуры** — удобная навигация

### Инфраструктура
- **Docker** — контейнеризация всех сервисов
- **Docker Compose** — оркестрация контейнеров
- **Gunicorn** — production WSGI сервер
- **Nginx** — обратный прокси и раздача статики

## 🚀 Быстрый старт

### Предварительные требования
- Установленные Docker и Docker Compose
- Git
- Telegram Bot Token (получить у @BotFather)

### Установка и запуск

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/AlenaZaidullina/sitdipsy.git
   cd sitdipsy
   
2. **Настройте переменные окружения**
    ```bash
    cp .env.example .env

3. **Запустите проект через Docker**
    ```bash
   docker-compose up -d
   
4. **Примените миграции**
    ```bash
   docker-compose exec web python manage.py migrate

5. **Создайте суперпользователя для админки**
    ```bash
   docker-compose exec web python manage.py createsuperuser
   
6. **Настройте Telegram бота**
    ```bash
   docker-compose exec web python manage.py setbotmenu
    docker-compose up telegram-bot
